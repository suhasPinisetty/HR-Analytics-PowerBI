# HR Analytics Dashboard | Power BI

Interactive HR Analytics dashboard built using **Power BI, Power Query, and DAX**.

## Project Overview

This project analyzes employee attrition, compensation, demographics, satisfaction, performance, and workforce risk through an interactive 4-page Power BI dashboard.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Interactive Data Visualization

## Dashboard Pages

1. **HR Analytics – Executive Overview**
2. **Employee & Compensation Analysis**
3. **Employee Risk & Satisfaction Analysis**
4. **HR Analytics – Interactive Analysis**

## Key Features

- KPI cards for workforce and attrition metrics
- Employee attrition analysis by department, job role, age, gender, overtime, and tenure
- Compensation analysis by salary band, job level, department, and job role
- Employee satisfaction, performance, promotion, and risk analysis
- Cross-page slicers for Department, Gender, and Age Band
- Interactive dashboard for dynamic workforce analysis
